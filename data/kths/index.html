ClassificationEntry

Represents a single entry for classifying an entity to a vocabulary term

These are used to create the final classification for an entity. This is done by ordering the classification entries based on their scores, with higher scores indicating greater confidence.

The last_updated field should be used as a tie-breaker when scores are equal, with later timestamps taking precedence.

For entries where the Vocabulary is single, the highest scoring entry should be selected as the final classification.

For entries where the Vocabulary allows multiple entries, all entries with sufficiently high scores should be considered for the final classification.

If a classification entry is marked with exclude=True, all entries for that term with a lower score should be disregarded when determining the final classification.

Title Property Type Required Description Examples

One of Operator, Site

The vocabulary term for this classification entry
Score score

integer

 Yes

The confidence score for this classification entry. Higher values indicate greater confidence.
Exclude exclude

boolean

 No

Indicates whether this classification entry indicates that the term should be excluded from consideration. False means that this is a positive result for the classification

string

 Yes

The timestamp of the last update for this classification entry
